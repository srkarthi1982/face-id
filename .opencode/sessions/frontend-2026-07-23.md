## Technical Details

### Store Pattern
Used manual Zustand pattern (not createCrudStore) because:
- More control over API calls
- Better error handling
- Clearer type safety
- Follows existing location store pattern

### API Integration
- Direct client calls to `/api/v1/personnel/` endpoints
- Handles pagination metadata from backend
- Supports filtering by name
- Implements soft delete (204 No Content handling)

### Component Structure
```
PersonnelPage (module entry)
  └─ PersonnelListPage (uses CrudPage)

```
