# Agent Session Notes

This directory contains daily session notes from agent-assisted development.

## File Naming Convention
- `backend-YYYY-MM-DD.md` - Backend developer session
- `frontend-YYYY-MM-DD.md` - Frontend developer session

## Session Note Template

```markdown
# [Backend/Frontend] Session - YYYY-MM-DD

**Developer:** [Name]
**Track:** X.X - <Track Name>
**Status:** COMPLETE / IN PROGRESS / BLOCKED

## Session Goal
<What you planned to accomplish>

## Work Completed
- [ ] Task 1
- [ ] Task 2
- [ ] Task 3

## Files Created/Modified
- `path/to/file.py`

## Code Snippets
```python
# Any important code snippets
```

## Issues/Blockers Encountered
<Any issues encountered>

## Testing Performed
<Any tests run>

## Next Session Plan
<What to work on next>

## Notes for Next Agent
<Any context the next agent should know>
```

## How to Use
1. Create a new session file at the start of each day
2. Fill in the template as you work
3. Update progress log at end of session
4. Commit session file with your work
